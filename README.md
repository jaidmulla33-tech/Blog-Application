# Inkwell – Full Stack Blog Application

Blog app built during my Full Stack internship at Codomax Digital Solutions.

## Progress
- [x] Module 1: Frontend (HTML, CSS, JavaScript)
- [x] Module 2: Backend (Node.js, Express)
- [ ] Module 3: Database integration
- [ ] Module 4: CRUD operations
- [ ] Module 5: Authentication and dashboard
- [ ] Module 6: Final project and deployment

## Tech stack
HTML, CSS, JavaScript, Node.js, Express.js

## Run locally
1. Backend:
   ```
   cd backend
   npm install
   npm start
   ```
2. Keep it running, then open `frontend/index.html` with VS Code Live Server.

## API
- POST /api/auth/register
- POST /api/auth/login
- GET /api/blogs
- POST /api/blogs
